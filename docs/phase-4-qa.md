# QA دستی فاز ۴

پیش‌نیاز: `pnpm infra:up`، `db:seed`، `SMS_PROVIDER=console`، API روی ۳۰۰۰ و وب روی ۳۰۰۱.

## ۱) جریان کامل
1. پنجره‌ی ناشناس A: ورود با `09120000002` (کد در لاگ API) ← جستجو ← پزشک ← انتخاب روز/ساعت ← ثبت.
2. پنجره‌ی ناشناس B: ورود به‌عنوان پزشک (شماره‌ی seed پزشک) ← `/doctor` ← «تأیید نوبت».
3. A: صفحه‌ی نوبت را تازه کنید ← وضعیت «تأییدشده» ← «لغو نوبت» ← تأیید ← وضعیت «لغوشده».
- انتظار: بدون خطای کنسول؛ بدون هیچ پیام فنی انگلیسی برای کاربر.

## ۲) دو تب هم‌زمان
1. در یک پنجره دو تب از اپ (واردشده) باز کنید.
2. در تنظیم کوتاه‌مدت JWT (مثلاً ۳۰ ثانیه) صبر کنید تا access token منقضی شود، سپس در هر دو تب هم‌زمان روی «نوبت‌های من» بزنید.
   - انتظار: در تب Network فقط **یک** `POST /auth/refresh`؛ هیچ‌کدام خارج نمی‌شوند.
3. در تب ۱ «خروج» بزنید ← انتظار: تب ۲ خودکار به حالت مهمان می‌رود.
4. قطع شبکه (DevTools ← Offline) و بارگذاری مجدد ← انتظار: «اتصال برقرار نشد» با «تلاش دوباره»، نه صفحه‌ی ورود.

## ۳) دسترس‌پذیری پایه (کیبورد + خوانشگر)
روی `/`، `/login`، `/doctors/[id]`، `/appointments/[id]`:
- فقط با Tab/Shift+Tab/Enter/Space کار انجام شود؛ فوکوس همیشه دیده شود.
- پیوند «رفتن به محتوا» با اولین Tab ظاهر شود.
- مودال لغو: فوکوس داخل مودال بماند، Esc ببندد، فوکوس به دکمه‌ی قبلی برگردد.
- خوانشگر: عنوان مودال، خطاها (`role=alert`) و روز/ساعت انتخاب‌شده (`aria-pressed`) خوانده شود.
