# ۹. قالب تحویل توسعه

## Handoff
- مرحله/اسپرینت:
- وضعیت: انجام شد / ناقص / مسدود
- Commit/PR:
- فایل‌های تغییرکرده:
- Schema/migration:
- ADR/تصمیم جدید:
- فرمان‌ها و نتیجه:
- Unit/Integration/E2E:
- شواهد CI/staging:
- تغییر env:
- مسائل باز و شدت:
- ریسک امنیت/حریم خصوصی:
- بازبین:
- rollback/feature flag:
- مرحله بعد:

## چک‌لیست PR
- [ ] مسئله و معیار پذیرش روشن.
- [ ] API contract و خطاها به‌روز.
- [ ] migration در صورت نیاز.
- [ ] مجوز، مالکیت و consent بررسی شده.
- [ ] edge case و idempotency بررسی شده.
- [ ] تست مناسب اضافه/اصلاح شده.
- [ ] UI دارای loading/empty/error است.
- [ ] log فاقد PHI/secret است.
- [ ] env/docs به‌روز است.
- [ ] CI سبز و review دوم ثبت شده.
- [ ] rollback/feature flag وجود دارد.

## گزارش باگ
عنوان؛ محیط/commit؛ نقش؛ پیش‌شرط؛ مراحل بازتولید؛ انتظار؛ واقعیت؛ شدت؛ آیا داده حساس درگیر است؟؛ log پاک‌سازی‌شده/correlation ID؛ مالک/موعد؛ نتیجه تست مجدد.
