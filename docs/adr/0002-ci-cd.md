# ADR 0002 — CI/CD روی GitHub Actions با یک gate

**وضعیت:** پذیرفته‌شده

**زمینه:** پروژه‌ی داده‌ی سلامت است؛ نشت secret، شکستن RLS یا بازگشت stub پرداخت هزینه‌ی بالا دارد و CI وجود نداشت.

**تصمیم**
- یک workflow با jobهای موازی و یک job ی «CI gate»؛ branch protection فقط همین را می‌خواهد (افزودن job جدید نیازی به تغییر تنظیمات ندارد).
- تست integration روی Postgres/Redis واقعی (نه mock)، چون ادعاهای اصلی (RLS، EXCLUDE، Audit) فقط در دیتابیس واقعی اثبات می‌شود.
- gitleaks در CI و pre-commit؛ Trivy فقط HIGH/CRITICAL با `ignore-unfixed`؛ semgrep با قواعد اختصاصی پروژه.
- `--frozen-lockfile` اجباری؛ بدون lockfile CI شکست می‌خورد.
- gitleaks و actionlint از image های Docker با نسخه‌ی ثابت اجرا می‌شوند (بدون وابستگی به license یا action ی شخص ثالث).

**پیامد:** merge بدون CI سبز ممکن نیست؛ هزینه: ~۱۰–۱۵ دقیقه برای هر PR (cache ی pnpm/turbo آن را کم می‌کند).
