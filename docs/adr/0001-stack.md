# ADR-0001: انتخاب استک

- **وضعیت:** پذیرفته‌شده
- **تصمیم:** NestJS (TypeScript) + PostgreSQL 16 + Prisma + Redis، مونولیت ماژولار؛ MinIO برای فایل؛ LiveKit برای ویدئو (فاز ۷).
- **دلایل:** Guard/Interceptor برای نقش و ممیزی؛ RLS و EXCLUDE در Postgres برای امنیت و جلوگیری از رزرو دوبل؛ یک زبان در کل پروژه؛ تفکیک ساده‌ی ماژول‌ها در آینده.
- **پیامدها:** Prisma از EXCLUDE/RLS پشتیبانی بومی ندارد → مهاجرت‌های SQL خام لازم است. میزبانی داخل کشور = Postgres خودمیزبان.
- **بازنگری:** پایان فاز ۳.
