# ADR 0004 — انتشار ایمن با SBOM و امضای keyless

- وضعیت: پذیرفتهشده (فاز ۲۴)
- تاریخ: ۱۴۰۵/۰۹/۰۱

## زمینه
تصویر Docker نهایی باید قابلردیابی و قابلتأیید باشد تا در زنجیرهٔ تأمین نرمافزار، جایگزینی مخرب شناسایی شود.

## تصمیم
- هنگام انتشار (برچسب `v*`) یک SBOM با قالب SPDX توسط Syft تولید میشود.
- تصویر با Cosign و هویت OIDC GitHub Actions بهصورت keyless امضا میشود.
- گواهی منبع (SLSA provenance) بهعنوان attestation به تصویر متصل میشود.
- در محیط پروداکشن فقط تصاویر دارای امضای معتبر دریافت میشوند.

## پیامدها
- (+) قابلیت تأیید منبع و محتوای تصویر هنگام استقرار.
- (+) عدم نیاز به ذخیرهٔ کلید خصوصی طولانیمدت در CI.
- (−) نیاز به دسترسی `id-token: write` در GitHub Actions.
- (−) جریان انتشار فقط روی برچسب اجرا میشود، نه روی pull request.
