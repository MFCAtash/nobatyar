# ADR 0007 — اجرای استرداد وجه با تأیید ادمین و ماشین‌حالت امن

**تصمیم:** استرداد فقط با اقدام ادمین، claim اتمیک، نتیجه‌ی مبهم ⇒ REVIEW بدون تکرار خودکار، درگاه‌های بدون API ⇒ MANUAL با ثبت مرجع، سقف مبلغ و نهایی‌بودن در تریگر DB، Audit کامل.
**چرا نه job ی خودکار؟** حرکت پول بدون API ی ایدمپوتنت؛ خطای اجرای مجدد گران‌تر از تأخیر چند ساعته است.
**جایگزین‌های ردشده:** تلاش مجدد خودکار پس از timeout (خطر استرداد دوباره)؛ تغییر `Payment.status` فقط پس از PROCESSED (ریسک شکستن منطق هماهنگی نوبت/ترمیم؛ به‌جایش معنای status مستند شد).
**پیامد:** مهاجرت `phase13-refunds.sql`؛ توکن دسترسی زرین‌پال راز جدید؛ دو فرض زرین‌پال باید در sandbox راستی‌آزمایی شود.
