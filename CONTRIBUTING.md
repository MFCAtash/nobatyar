# Contributing / مشارکت

**این مخزن فقط خواندنی است (view-only).** مالک هیچگونه مجوز کپی، فورک یا مشارکت عمومی نمیدهد.

> This repository is **view-only**. No public contributions, forks, or copy licenses are granted.

- Patent or security issues: report privately per `SECURITY.md`.
- Bugs/ideas: open an **Issue** with clear reproduction steps; do not open a PR.
- Code contributions are accepted **by written invitation only** and require a signed contributor agreement.

If you want to build something similar, please request written permission at `mohammadatash62@gmail.com`.

برای مشارکت کدی فقط با دعوت کتبی امکانپذیر است. در غیر این صورت لطفاً فقط Issue ثبت کنید.
